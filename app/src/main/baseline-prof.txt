# Baseline profile: tells ART which code to compile ahead of time at install, instead of
# interpreting/JIT-ing it during the first launches after every install or update.
#
# The rules use source names. At build time AGP expands the wildcards against the real classes and
# R8 rewrites the result to the minified names, so these rules stay valid as the code changes:
# there is nothing to regenerate. Rules that match nothing are ignored.
#   HSPL<class pattern>-><method pattern>   compile the matching methods (hot/startup/post-startup)
#   L<class pattern>;                        preload the matching classes
#   ** matches anything, including '/'

# All of the app's own code (assistant overlay, settings, generated Hilt components)
HSPLcom/joyal/swyplauncher/**->**(**)**
Lcom/joyal/swyplauncher/**;
